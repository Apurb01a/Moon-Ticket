# Discord Ticket Bot (Node.js)

This is a simple ticketing system for Discord using buttons.

## Setup

1. Install dependencies:

```
npm install
```

2. Create a `.env` file with your bot token:

```
DISCORD_TOKEN=your_bot_token_here
```

3. Start the bot:

```
node index.js
```

4. Use `!sendticket` in a channel to post the button.
